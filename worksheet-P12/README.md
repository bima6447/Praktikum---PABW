# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).

## Penggunaan AI - Pertemuan 12

* **Bagian yang Dikerjakan Mandiri**:
  * Pengujian reaktivitas komponen dan logika filter data proyek.
  * Implementasi kode fungsi persistensi `localStorage` dan *error handling* (`try-catch`).
  * Eksekusi perintah *build* produksi (`npm run build` & `npm run preview`).
  * Pengukuran serta pengambilan metrik performa di Chrome DevTools tab Network.

* **Bagian yang Dibantu AI**:
  * Diskusi dan konsultasi pemecahan masalah (*troubleshooting*) saat menemukan kendala/galat.
  * Pemahaman teori *troubleshooting* (kasus *case-sensitivity*, pengelolaan `.gitignore`, dan direktori `dist/`).
  * Penyusunan dan perapian format dokumentasi berkas `README.md`.
